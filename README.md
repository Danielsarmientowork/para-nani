# Órbita

Página web de producto para **Órbita**, una mochila inteligente para estudiantes universitarios (proyecto universitario, producto ficticio).

## Estructura

```
orbita-web/
├── index.html
├── css/
│   └── style.css
├── .nojekyll
└── README.md
```

## Ver en local

Abre `index.html` en tu navegador. No necesita instalación.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `orbita`).
2. Sube **el contenido** de esta carpeta a la raíz del repositorio (que `index.html` quede en la raíz, no dentro de otra carpeta).
3. Ve a **Settings → Pages**.
4. En *Build and deployment*, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
5. Guarda y espera uno o dos minutos. Tu página estará en `https://TU-USUARIO.github.io/orbita/`.
